# Morgan Moore Portfolio

## Overview

This repository contains my personal software development portfolio. The portfolio highlights my skills, technologies, and software projects while demonstrating JavaScript concepts such as objects, arrays, DOM manipulation, and browser storage.

Project information is stored as JavaScript objects within an array. The project data is converted to JSON and stored in sessionStorage, then retrieved and dynamically rendered on the page.

## Languages and Technologies

- HTML
- CSS
- JavaScript
- Python
- GitHub
- Docker
- Kubernetes

## Features

- Responsive portfolio structure
- Dark mode with saved user preference
- Dynamically generated skills list
- JavaScript project objects and arrays
- Dynamic project rendering using DOM manipulation
- Project data storage using JSON and sessionStorage
- Contact form with submission feedback
- Welcome modal

## Projects

The portfolio currently features projects including:

- Heart Disease Risk Prediction
- StudySprint Mobile Application
- Rolodex Contact Manager

Each project includes a title, summary, image, and link to its GitHub repository.

## Dependencies

This project does not require any external libraries or dependencies. It uses standard HTML, CSS, and JavaScript and can be run directly in a modern web browser.

## Running the Portfolio

To run the portfolio locally:

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.

The portfolio is also published using GitHub Pages.
